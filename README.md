# AI Booking Agent

An intelligent booking assistant project focused on AI agents, backend engineering, MongoDB, APIs, automation, testing, and system design.

## Project Goals

- Build an intelligent booking workflow
- Learn MongoDB and NoSQL data modeling
- Build framework-independent AI logic
- Design REST APIs
- Implement conversation memory
- Add booking state management
- Integrate LLM tools safely
- Add testing and security practices
- Document architecture and engineering decisions

## Current Phase

Phase 1 — Foundation & Repository Setup

## Planned Technologies

- Python
- MongoDB
- FastAPI
- LLM APIs
- Pytest
- Docker
- GitHub Actions

Additional technologies may be introduced later, including ASP.NET Core and relational databases for comparison and expansion.
